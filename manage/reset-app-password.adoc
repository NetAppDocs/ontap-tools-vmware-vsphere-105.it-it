= Reimposta la password utente dell'applicazione in ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Segui questi passaggi per reimpostare la password dell'utente dell'applicazione necessaria per la registrazione SRA e VASA Provider con vCenter Server utilizzando ONTAP tools for VMware vSphere.

.Passaggi
. Apri un browser web e vai a: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Accedi utilizzando le credenziali di amministratore configurate durante la distribuzione degli ONTAP tools.
. Dalla barra laterale, seleziona *Impostazioni*.
. Nella pagina *Credenziali VASA/SRA*, seleziona *Reimposta password*.
. Inserisci e conferma la nuova password.
. Seleziona *Reset* per applicare la nuova password.
