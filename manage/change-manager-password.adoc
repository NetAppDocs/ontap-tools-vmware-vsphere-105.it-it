= Cambia la password di ONTAP tools Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi cambiare la password dell'amministratore usando ONTAP tools Manager.

.Passaggi
. Avvia ONTAP tools Manager da un browser web: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Accedi con le credenziali di amministratore degli ONTAP tools for VMware vSphere.
. Seleziona l'icona *administrator* nell'angolo in alto a destra dello schermo e seleziona *Change password*.
. Nella finestra a comparsa per la modifica della password, inserisci la vecchia e la nuova password. La schermata dell'interfaccia utente mostra i requisiti della password.
. Seleziona *Modifica* per applicare le modifiche.
