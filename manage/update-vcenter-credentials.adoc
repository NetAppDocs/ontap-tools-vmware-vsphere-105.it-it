= Aggiorna le credenziali del server vCenter negli ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi aggiornare le credenziali dell'istanza vCenter Server usando la console di manutenzione.

.Prima di iniziare
Devi avere le credenziali di accesso dell'utente di manutenzione.

.Informazioni su questa attività
Se hai modificato le credenziali del server vCenter dopo la distribuzione, aggiornale seguendo questa procedura.

.Passaggi
. Dal vCenter Server, apri una console per VASA Provider.
. Accedi come utente di manutenzione.
. Premi Invio `2` per selezionare il menu Configurazione di sistema.
. Inserisci  `8` per modificare le credenziali di vCenter.
