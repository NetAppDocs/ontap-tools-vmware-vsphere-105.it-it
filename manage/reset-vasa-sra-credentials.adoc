= Reimposta le credenziali del provider VASA e SRA negli strumenti ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se dimentichi le tue credenziali VASA Provider o SRA, puoi reimpostarle con una nuova password tramite l'interfaccia ONTAP tools Manager. La nuova password deve essere lunga tra 8 e 256 caratteri.

.Passaggi
. Avvia ONTAP tools Manager da un browser web: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Accedi con le credenziali di amministratore degli ONTAP tools for VMware vSphere che hai fornito durante la distribuzione.
. Seleziona l'opzione *Impostazioni* > *VASA Provider / SRA credentials* > *Reset Password*.
. Inserisci la nuova password e confermala.
. Seleziona *Salva* per applicare le modifiche.
